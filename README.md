# EAI-Goety-Patch
Fixed the compatibility issue with apostle spawning in EAI and Goety.
It only adds null pointer checks through Mixin, so it should be compatible with most mods.
Players can use this mod to fix the issues that occur when Goety and EAI are installed together, where Apostles in Goety cannot be summoned, and the game crashes when Apollyon from Goety: Relevation is summoned.
